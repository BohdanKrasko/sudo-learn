# Student submissions

Create one folder here named exactly after your GitHub username. Copy the
task's `TEMPLATE.md` into that folder as `README.md`, then add your
`audit-permissions.sh` script.

```text
submissions/
└── octocat/
    ├── README.md
    └── audit-permissions.sh
```

Do not commit private notes, complete account databases, usernames, hostnames,
or unrelated system output. Do not edit another student's folder.
