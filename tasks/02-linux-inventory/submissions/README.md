# Student submissions

Create one folder here named exactly after your GitHub username. Copy the
task's `TEMPLATE.md` into that folder as `README.md`, then add your
`inventory.sh` script.

```text
submissions/
└── octocat/
    ├── README.md
    └── inventory.sh
```

Keep generated reports in `/var/logs/system-inventory/` on your Linux machine.
Do not commit them or edit another student's folder.
